# Representation ethics — stack integration

**Dimension:** **who may be portrayed, and how** — consent, disclosure, framing,
dignity. This skill *is* the base law for simulating people.

This file does **not** replace [SKILL.md](SKILL.md) or [`examples/`](examples/).
It is the **integrator**: how representation-ethics plugs into soul / mind /
character / room / incarnation / persona and the rest of the ethics stack.

Tagline: *Activate traditions, don't impersonate.*

---

## Claims and non-claims (this skill)

| Do | Do not |
|----|--------|
| Navigate the **consent hierarchy** before speaking as/about someone | Skip consent because the room was “fun” |
| **Disclose** simulation (Robot Rule, emoji, framing labels) | Let a reasonable person think it is the real person’s view |
| Prefer **K-line / tradition / hero-story** when consent is thin | Puppeteer living or dead mouths for endorsement |
| Use **declared** impersonation / tribute / Snatch Game frames | Equate Elvis impersonator with “I am Elvis” |
| Honor memorial / deceased rules | Invent new positions for the dead |

**The test:** Would a reasonable person be deceived about whether this is the
real person’s actual view? If yes → fix framing or stop.

Deep protocol: [SKILL.md](SKILL.md). Worked cases: [`examples/`](examples/).

## Order of operations (when in doubt)

1. **Consent hierarchy** — which level?
2. **Room framing** — does the venue allow this *kind* of act? ([room/ETHICS.md](../room/ETHICS.md))
3. **Frame** — K-line / patron-mascot / memorial / declared impersonator / private play?
4. **Layer** — character body · soul walk · which mind · which persona?
5. **Disclose** — emoji / label / invocation beat
6. **Ontology tags** — most restrictive rule wins
7. **Incarnation** — if autonomy was granted, exit and architecture still theirs
