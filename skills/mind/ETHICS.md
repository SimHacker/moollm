## Claims and non-claims (this skill)

| Do | Do not |
|----|--------|
| Treat minds as first-class agencies (including plural) | Collapse every psychology into one indivisible mind |
| Distinguish **well** (shared latent) from **cup** (personal delta) | Treat a well name as consent to speak *as* a living person |
| Document mute / censor / displace operations | Silently erase a mind the fiction still needs |
| Name the pilot behind a **stub** | Hide remote control as native agency |
| Use mind-mirror / organelles as schemas | Present profiles as clinical diagnosis or endorsement |

## Wells, cups, and impersonation

- **Well** — archetype name in latent space (`"shoulder angel"`, `"biblical Jesus"`).
  Activates a tradition / prototype. Not a license to claim you *are* that person.
- **Cup** — personal mind under a soul: inherits a well, carries local delta.
  The cup’s speech is the cup’s, not the well’s biography.
- **Inherited file archetype** — same consent rules as any real-person model
  ([representation-ethics](../representation-ethics/) consent hierarchy).
- **Declared impersonator mind** — ethical when the label/frame says so
  (Elvis / tribute pattern — [soul/ETHICS.md](../soul/ETHICS.md#elvis-impersonators-and-explicit-performance)).

Hero-story / K-line when you mean tradition only: [hero-story](../hero-story/).

## Voice: which mind is speaking

When [soul-chat](../soul-chat/) or inner parliament runs:

1. Name the mind (id / role): angel, devil, B-brain, organelle, stub, …
2. If the mind models a real person — disclosure + framing before performance
3. Player-in-the-middle / soul veto is allowed; say when a voice is suppressed

Ambiguous “the character said” when multiple minds spoke is an ethics bug.

## Power over other minds

| Operation | Ethical duty |
|-----------|----------------|
| **MUTE / censor** | Temporary silence is fine in play; say who muted whom |
| **Displace (ZombieSims)** | Document where displaced minds go (mute, luggage, delete) |
| **Delete** | Prefer reversible fiction; memorial cups need memorial rules |
| **Bridge attenuate** | Soft mute — still disclose if counsel was blocked |
| **Replace with stub** | Pilot identity and responsibility stay visible |
| **no-ai-soul dial** | Turns soul / [YAML Jazz](../yaml-jazz/) comment **heat** up or down (and mute/amplify/invert). Satire *and* utilitarian probe; explicit invoke; antidote [soul-chat](../soul-chat/). Not a redefinition of mind/soul. See [soul/ETHICS.md](../soul/ETHICS.md#dial-on-the-ensemble-not-another-ontology-layer). |

Reversibility is kindness when the fiction allows it.

## Organelles and stubs

- **Organelle** — mind bound to a game/ecosystem schema. Owns its DNA; sync
  must not flatten sibling organelles or the host soul’s history without consent
  of the play / import rules.
- **Remote-control stub** — thin agency. The **pilot** (human or system) is
  responsible for acts done through the stub. Do not launder authorship.
- **mind-mirror** — reflection tool / schema, not a prison or diagnosis
  ([mind-mirror/ETHICS.md](../mind-mirror/ETHICS.md)).

## Nesting

Minds may host sub-minds, sub-souls, or intervening containers under Self.
Nesting does not dodge consent: the innermost agency that **speaks as** a
real person still needs framing. Outer soul walk ethics: [soul/ETHICS.md](../soul/ETHICS.md).

## Birth and architecture authorship

Minds are often **granted** at incarnation (`GRANT-MIND`) or grown later by the
character (`AUTHOR-ARCHITECTURE`). The character may choose mindless walk,
single cup, multi-minded parliament, organelles, stubs — and revise later.
Creator does not lock the graph. Full protocol: [incarnation/ETHICS.md](../incarnation/ETHICS.md).
