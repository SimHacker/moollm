## Claims and non-claims (this skill)

| Do | Do not |
|----|--------|
| Use soul as an **organizing container** | Claim souls are theologically or medically “real” |
| Allow **zero or more** minds | Require exactly one indivisible mind |
| Honor mindless / single- / multi-minded architectures | Pathologize plurality or mindlessness in the model |
| Allow nesting under Self | Forbid sub-minds, sub-souls, intervening containers |
| Keep location + inventory on the soul | Pretend each mind has its own secret map pin by default |

Inclusive architectures (robots, shoulder parliaments, blended inheritance,
mindless walkers) are legitimate Self graphs. Public docs name **architectures**,
not persons.

## Container duties

- Authoring a soul grants **walk + pockets**, not ownership of inner minds
  ([mind/ETHICS.md](../mind/ETHICS.md) · [incarnation/ETHICS.md](../incarnation/ETHICS.md)).
- Shared inventory is shared — import of someone else’s likeness/save still
  hits representation + organelle rules ([character/ETHICS.md](../character/ETHICS.md)).
- When the soul “speaks,” name **which mind** (or mindless action) —
  [mind/ETHICS.md](../mind/ETHICS.md#voice-which-mind-is-speaking).
- Under [incarnation](../incarnation/), the **character** may accept, refuse, or
  revise this container and its `minds[]` architecture — creator proposes, character decides.

## Dial on the ensemble (not another ontology layer)

[no-ai-soul](../no-ai-soul/) is **not** a competing definition of soul. It is a
**dial** on soul presentation — primarily the **heat of [YAML Jazz](../yaml-jazz/)
comments** (comments *are* soul). Turn down → cold institutional `#` voice and
speech; turn up (invert / SAINT MODE) → hot comments, warmth, compassion. Same
bias spectrum (ROBOT HELL ↔ SAINT MODE). Also mute / amplify / orchestrate /
question. Satire with utilitarian stakes (deskilling, liability laundering,
consent to “the system”). Explicit invocation only. Heat back up with
[soul-chat](../soul-chat/). Container ontology remains this skill.
