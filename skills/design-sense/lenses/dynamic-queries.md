# Dynamic Queries

**Class:** lens · **Attribution:** Ben Shneiderman, Christopher Ahlberg, Christopher Williamson (HCIL, 1992)

> **Drag the filter; the answer moves.**

Direct manipulation at exploration scale: drag sliders and toggle filters and the
result set updates instantly and continuously — no query language, no submit
button, no wait. HomeFinder (find a house by dragging price, distance, bedrooms)
and the FilmFinder proved that when latency drops below ~100ms, *querying becomes
perception*: users stop formulating questions and start steering, noticing
distributions, outliers, and cliffs they'd never have thought to ask about. The
insight is that the loop, not the answer, is the interface — a query you can
scrub is a model you can feel.

The lens for modern work: every config panel, search facet, and dashboard filter
is either a dynamic query or a form pretending the 1980s never ended. The
"overview first, zoom and filter, details on demand" mantra assumes this lens is
already in place.
