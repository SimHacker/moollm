# Stage Magic

**Class:** lens · **Attribution:** David Ungar (the Stage Magic Principle, from Self's morphs)

> **Simple view until complex truth.**

The magician controls where the audience looks: the trick is not hiding the
machinery, it's *sequencing the reveal* so the audience sees the simple story
first and the machinery only when they ask. In Self's morphic UI, a morph looks
like one solid object until you pop it open and find the composite parts — the
complexity was always there, reachable, but never volunteered. The lens
generalizes to every surface: the API with the three-line happy path and the
full parameter surface behind it; the doc whose first paragraph works without
the appendix; the game tutorial that is secretly the first level.

Two corollaries with teeth:

- **Reachability is the ethics.** Stage magic without a way backstage is deception;
  the difference between a magic show and a con is that the theater has doors.
  Shift-click should open the widget ([HyperLook](../masters/arthur-van-hoff.md)
  had this on a hinge).
- **The reveal is a reading order, not a wall.** moollm's GLANCE → CARD → SKILL →
  README pyramid is stage magic operationalized: every level is public, but the
  coarse level always plays first ([semantic-mipmap](semantic-mipmap.md)).
