# K-Line Activation

**Class:** lens · **Attribution:** Marvin Minsky ("K-Lines: A Theory of Memory", 1980)
**Dispatch:** whole skill at moollm [skills/k-lines/](../../k-lines/) — load it; this entry is the design-sense pointer.

> **The name is the activation.**

Minsky's theory of memory: when you solve a problem, a K-line forms that records
which mental agents were active; invoking it later *reactivates that partial
mental state* — you don't recall a fact, you re-become the person who solved it.
The design consequence is everywhere in this repo: a name is a stored attention
mask, so mint names deliberately and prefer activation by name over pasting the
essay. "COPY-THAT for HN" loads a whole protocol in four syllables; "Fitts"
reopens fifty years of pointing research; a well-named directory teaches its
contents before a single file opens.

For interfaces: command names, icons, and menu labels are K-lines the user
accretes — [memorably-differentiate-commands](memorably-differentiate-commands.md)
is about making each one attach cleanly. For LLM work: latent space is prepaid
K-lines; pointing beats respelling ([lean-into-latent](lean-into-latent.md)).
