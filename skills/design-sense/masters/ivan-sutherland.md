# Ivan Sutherland

**Class:** master · **Head:** constraints as conversation; the display as window into a mathematical wonderland

Sketchpad (1963) is the common ancestor: draw a rough figure, declare the
constraints (parallel, equal, attached), and watch the system *maintain* them —
the first direct-manipulation interface, the first object instances, the first
constraint solver in a UI, all in one thesis. "The Ultimate Display" (1965) set
the far pole: a room where the computer controls the existence of matter — VR's
founding paragraph. The head-mounted display (1968) started cashing that check.
The design stance: don't tell the computer what to draw; tell it what must stay
true, and let it draw.

## Votes

- **Declare what must stay true and let the system maintain it** — the constraint
  is the program ([gesture-space-constraints](../lenses/gesture-space-constraints.md);
  heirs: [brad-myers](brad-myers.md), [rich-harris](rich-harris.md))
- **Converse with the machine in geometry** — draw the rough thing, then refine by
  constraint, not by coordinates
  ([direct-manipulation](../lenses/direct-manipulation.md) before the term existed)
- **Make the master drawing an instance factory** — Sketchpad's masters and
  instances prefigure prototypes: edit the master, every instance follows
  ([../methods/instance-substitution.md](../methods/instance-substitution.md))
- **Treat the display as a window into a mathematical wonderland** — and choose the
  wonderland deliberately
  ([The Ultimate Display, 1965](https://www.wired.com/2009/09/augmented-reality-the-ultimate-display-by-ivan-sutherland-1965/))
- **Ask the courage question** — "I didn't know it was hard" is a research method:
  the [Sketchpad thesis](https://www.cl.cam.ac.uk/techreports/UCAM-CL-TR-574.pdf)
  was possible because nobody told him it wasn't

## Vetoes

- Don't redraw by hand what a constraint could maintain
- Don't make the user translate geometry into text
- Don't mistake the display for the thing — it's a window, so decide what world it opens onto
