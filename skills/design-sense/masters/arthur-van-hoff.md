# Arthur van Hoff

**Class:** master · **Head:** live authoring in the shipped medium; self-hosting

The through-line from GoodNEWS to Bongo: the authoring tool lives *inside* the
running medium, and the shipped artifact stays editable. At the Turing Institute:
GoodNEWS → HyperNEWS → HyperLook, the HyperCard of NeWS — every widget in a
running application editable in place, interfaces made of PostScript objects you
could shift-click open (the surface Don Hopkins ported SimCity into). PdB, his
C-syntax object language compiling to NeWS PostScript, because a live medium
deserves a real compiler. At Sun: wrote javac *in Java* — the compiler
self-hosting as proof the language was real — and the AWT toolkit. Co-founded
Marimba: Castanet pushed live application updates over the network (the app store
and auto-update, a decade early), and Bongo was HyperLook reborn in Java — a
presentation builder whose widgets stayed live and editable.

## Votes

- **Keep the shipped artifact editable** — HyperLook interfaces stayed live
  PostScript objects; shift-click opened the machinery
  ([stage-magic](../lenses/stage-magic.md) with the curtain on a hinge;
  [the HyperLook history](https://donhopkins.medium.com/hyperlook-nee-hypernews-nee-goodnews-664d460a9491))
- **Self-host as proof** — writing javac in Java was the argument that the
  language was real; build the tool in the tool
  ([everything-is-concrete](../methods/everything-is-concrete.md))
- **Give the live medium a real compiler** — PdB compiled C-syntax objects to NeWS
  PostScript because liveness shouldn't cost rigor
  ([low-floor-no-ceiling](../methods/low-floor-no-ceiling.md) for substrates)
- **Push, don't reinstall** — Castanet updated running applications over the wire
  in 1996; the network is the distribution medium
  ([Wikipedia: Marimba](https://en.wikipedia.org/wiki/Marimba_(company)))
- **Rebuild the good idea on each new substrate** — GoodNEWS → HyperLook → Bongo:
  when the platform dies, the design conviction ports

## Vetoes

- Don't ship an authoring tool you didn't build the tool in
- Don't freeze at ship time what the network could keep alive
- Don't separate the editing surface from the running surface
