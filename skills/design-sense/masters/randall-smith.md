# Randall Smith

**Class:** master · **Head:** alternate realities; uniform worlds you can touch

The Alternate Reality Kit (Xerox PARC, 1986): physics as interface — every object
in the simulation is a concrete thing you grab, throw, and rewire while it runs,
with buttons wired to messages and gravity you can switch off. ARK posed the
tension between *literalism* (magic that follows the world's rules) and *magic*
(power that breaks them) as a design axis. Co-parent of Self with David Ungar:
prototypes instead of classes, because copying a concrete thing you can see beats
instantiating an abstraction you can't. Kansas: a shared flatland where
programmers inhabit one big space together and the environment itself is the
collaboration medium.

## Votes

- **Let them grab the physics** — in ARK, gravity is a switch and every simulation
  object is a thing in the hand
  ([everything-is-concrete](../methods/everything-is-concrete.md);
  [the ARK video](https://www.youtube.com/watch?v=w1HhPE0zVYY) is still the demo)
- **Choose literalism first, magic deliberately** — power that follows the world's
  rules teaches; power that breaks them must be spent like currency
  ("Experiences with the Alternate Reality Kit", CHI+GI 1987)
- **Copy the concrete thing you can see** — prototypes over classes, because the
  example is the explanation ([power-of-simplicity](../methods/power-of-simplicity.md),
  [instance-first](../methods/instance-first.md))
- **Inhabit the system together** — Kansas put all programmers in one shared
  flatland; the environment is the collaboration medium
  ([tourist-policy](../methods/tourist-policy.md) as an IDE)
- **Design the experience, then extract the language** — "Programming as an
  Experience" is the Self origin story: the feel came first
  ([ECOOP 1995](https://bibliography.selflanguage.org/programming-as-experience.html))

## Vetoes

- Don't make the user manipulate a description when they could manipulate the thing
- Don't spend magic where literalism would teach
- Don't hide the running system from the people changing it
