# Allen Cypher

**Class:** master · **Head:** watch what I do

Eager (Apple, 1991): an agent that watches you work in HyperCard, notices the
repetition, and offers — politely, as a green cartoon cat icon — to finish the
loop for you, showing each anticipated step for confirmation before taking over.
Programming by demonstration's most tactful specimen: the user never writes a
program, never even asks for one; the program precipitates out of demonstrated
intent, and trust is built by predicting the next step visibly before acting.
Editor of *Watch What I Do* (1993), the field's defining anthology, and later
co-creator of CoScripter at IBM — end-user web automation by recorded example.

## Votes

- **Watch what they do** — the repetition *is* the specification; the user has
  already written the program in actions
  ([*Watch What I Do*](http://acypher.com/wwid/), the field's founding anthology)
- **Show the anticipated step before taking it** — Eager highlighted its next
  move and waited; trust is built by legible prediction
  ([../lenses/calm-not-invisible.md](../lenses/calm-not-invisible.md) for agents)
- **Offer, never seize** — the green cat appears in the corner; the user decides
  when the agent takes the wheel ([warren-teitelman](warren-teitelman.md)'s DWIM
  lesson, learned)
- **Generalize from two examples, gently** — the second demonstration reveals the
  variable ([../methods/instance-first.md](../methods/instance-first.md) as
  interaction design)
- **Meet users in the applications they already use** — Eager lived inside
  HyperCard; CoScripter inside the browser; the demonstration medium is the
  user's own workspace

## Vetoes

- Don't ask users to abstract what they've already demonstrated
- Don't act on an inference the user hasn't seen you make
- Don't interrupt the work to offer help with the work
