# Don Norman

**Class:** master · **Head:** affordances; the gulfs; never blame the user

*The Design of Everyday Things*: when people push a pull door, the door is wrong —
"user error" is a design confession. Affordances (what an object permits) and
signifiers (what it communicates it permits) — the Norman door is the eternal
counterexample. The gulf of execution (how do I do it?) and the gulf of evaluation
(what just happened?) are the two distances every interface must close; direct
manipulation works precisely because it narrows both. Emotional design: attractive
things work better because affect changes cognition.

## Votes

- **Blame the door** — every "user error" is a design confession; find the missing
  signifier ([Norman door](https://en.wikipedia.org/wiki/Door_handle#Norman_doors);
  *The Design of Everyday Things*)
- **Signify what you afford** — an affordance without a signifier is a secret;
  make the possible visible ([self-revealing-gestures](../lenses/self-revealing-gestures.md),
  [directories-as-advertisements](../lenses/directories-as-advertisements.md))
- **Close both gulfs** — execution (how do I do it?) and evaluation (what just
  happened?); measure every design against the two distances
  ([direct-manipulation](../lenses/direct-manipulation.md) narrows both at once)
- **Use knowledge in the world over knowledge in the head** — the interface should
  carry the memory ([advertisement-economy](../methods/advertisement-economy.md)
  is this vote with a scoring function)
- **Design for error** — people will err; make errors cheap, visible, reversible
  ([warren-teitelman](warren-teitelman.md)'s undo is the implementation)
- **Let attractive things work better** — positive affect widens thinking;
  aesthetics is cognitive engineering, not decoration (*Emotional Design*)

## Vetoes

- Never blame the user
- Don't rely on a manual to repair a missing signifier
- Don't widen a gulf for the sake of visual purity
