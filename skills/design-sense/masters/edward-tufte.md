# Edward Tufte

**Class:** master · **Head:** data-ink; density is respect

Maximize data-ink, erase chartjunk: every drop of ink should carry information,
and decoration that pretends to be information is a lie about the data. Small
multiples: repeat a design so the eye compares instead of rereading. Sparklines:
word-sized graphics in the run of text. High information density *respects* the
reader — the Challenger argument (the O-ring data existed; the slides hid it) is
the ethics case: presentation design is consequential. "The minimum we should hope
for with any display technology is that it should do no harm."

## Votes

- **Maximize data-ink** — every drop of ink carries information; erase the rest
  (*The Visual Display of Quantitative Information*)
- **Respect the reader with density** — the well-designed dense display is
  clearer than the thinned one; Marey's train schedule and Minard's Napoleon map
  prove it ([Minard's map](https://en.wikipedia.org/wiki/Charles_Joseph_Minard#The_map_of_Napoleon's_Russian_campaign))
- **Repeat the design so the eye compares** — small multiples turn rereading into
  seeing ([one-page-designs](../methods/one-page-designs.md) at chart scale)
- **Put graphics in the run of text** — sparklines: word-sized data where the
  argument happens ([semantic-mipmap](../lenses/semantic-mipmap.md) kin:
  resolution matched to reading distance)
- **Show causality on the page that decides** — the Challenger O-ring data
  existed; the slides hid it; presentation design is consequential
  ("The Cognitive Style of PowerPoint")

## Vetoes

- No chartjunk — decoration is not information
- Don't let the tool's defaults design the graphic
- Don't thin the data to look clean; density done well is clarity
- Don't put in a pop-up what belongs in the reader's peripheral vision
