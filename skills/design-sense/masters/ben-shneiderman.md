# Ben Shneiderman

**Class:** master · **Head:** direct manipulation; measure the interface

Coined direct manipulation and gave it teeth: continuous representation, physical
actions over syntax, rapid reversible operations with visible results. The
empiricist of the bunch — the CHI'88 pie menu paper exists because his lab
measured menus instead of arguing about them. Dynamic queries brought direct
manipulation to databases (drag the slider, watch the answer); embedded links,
information visualization ("overview first, zoom and filter, then details on
demand"), and human-first framing (HCIL, universal usability) run through
everything.

## Votes

- **Keep the object of interest continuously visible** — representation persists;
  the user acts on the thing, not on a description of it
  ([direct-manipulation](../lenses/direct-manipulation.md))
- **Make every action rapid, incremental, and reversible** — with the result
  visible immediately; undo is what makes exploration safe
- **Slide the query and show the answer move** — no submit button between question
  and world ([dynamic-queries](../lenses/dynamic-queries.md))
- **Overview first, zoom and filter, then details on demand** — the visual
  information-seeking mantra, one sentence that designed a whole field
  (["The Eyes Have It", 1996](https://ieeexplore.ieee.org/document/545307))
- **Measure the interface** — run the experiment; the CHI'88 pie menu paper exists
  because his lab tested menus instead of theorizing
  ([fitts](../lenses/fitts.md))
- **Design for universal usability** — the novice, the expert, and the user with a
  disability are the same design problem at different settings

## Vetoes

- Don't hide the object of interest
- Don't demand syntax where a physical action would do
- Don't ship an irreversible operation and call it power
- Don't argue about interfaces you could measure
