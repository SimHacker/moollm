# Jens Mönig

**Class:** master · **Head:** first-class blocks; the implementor of no ceiling

Snap!'s builder: BYOB ("Build Your Own Blocks") began as the answer to Scratch's
hard ceiling — let kids define their own blocks, and make blocks *first-class*:
a block is a value you can pass, store, and construct, which smuggles lambda
into a child's palette without a single Greek letter. Custom blocks, upvars,
rings — each a careful piece of notation design making a deep idea (closures,
higher-order functions, continuations) *touchable* without diluting it. Also
GP (with John Maloney): blocks for "casual programmers" at production depth.
Career-long employer: SAP — the enterprise world funding the kindergarten lambda,
which he finds as funny as everyone else.

## Votes

- **Make it first-class or don't make it** — blocks as values smuggled lambda
  into the palette; every special case is a ceiling in disguise
  ([Snap! source](https://github.com/jmoenig/Snap);
  [../methods/low-floor-no-ceiling.md](../methods/low-floor-no-ceiling.md))
- **Let the shape teach the type** — puzzle-piece connectors, C-slots, and rings
  are type signatures the eye checks before the runtime does
  ([../lenses/memorably-differentiate-commands.md](../lenses/memorably-differentiate-commands.md))
- **Dress the deep idea** — continuations wearing cartoon costumes are still
  continuations; the dress-up is respect, not dilution
  ([../lenses/stage-magic.md](../lenses/stage-magic.md))
- **Build your own blocks** — the user who can extend the palette owns the
  language ([bill-atkinson](bill-atkinson.md)'s HyperCard vote, one level deeper)
- **Keep the whole system in one hand-written file you understand** — morphic.js
  is [dan-ingalls](dan-ingalls.md)' personal-mastery vote, running in a browser

## Vetoes

- Don't add a feature as a special case when a first-class value would generalize it
- Don't hide the deep idea — dress it
- Don't let the notation's cuteness cap its semantics
