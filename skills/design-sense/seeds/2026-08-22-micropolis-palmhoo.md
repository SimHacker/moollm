## Lens candidates

- **saturate-gesture-space** — Treat every press→path→release trajectory as covered
  vocabulary: every region means something (or cancel); sparse recognizers leave most
  of the space as syntax errors. — Don Hopkins, Buxton marking menus.
  MicropolisCore `documentation/designs/gesture-space-and-pie-menus.md`
- **angle-at-release** — Commit by the line from press to release, not the path taken;
  enables browse, preview, reselect, cancel-by-center. — Don Hopkins. Same source.
- **self-revealing-rehearsal** — Visible labels train the same motor pattern experts
  later flick without the popup; novice and expert paths must be continuous
  (mouse-ahead by rehearsal). — Buxton, Hopkins. Same source.
- **attention-stays-on-pointer** — Bring the mountain to Muhammad: slide the active
  label to the pointer; don't yank the eye to rim chrome. — Hopkins.
  `documentation/designs/virtual-pointer-and-pie-cursors.md` §6
- **no-spurious-velocity** — When the user lifts, intent is "stop here now";
  extrapolating motion past release decouples animation state from input state
  (momentum scroll, Mission Control half-modes). — Hopkins; Ron Reisman NASA 4D-TBO.
  `documentation/designs/classical-hci-vs-aesthetic-ui.md`, `four-dimensional-navigation-hci.md`
- **calm-not-invisible** — Weiser's calm means less interruption while the user stays
  in command, not hiding state for screenshot purity; visible state and reversible
  action beat chrome that lies about input. — Weiser & Brown; Shneiderman; Hopkins.
  `documentation/designs/classical-hci-vs-aesthetic-ui.md`
- **memorably-differentiate-commands** — Command sets that differ in cost, function,
  and relation must look and feel different, not a flat grid of identical hitboxes.
  — Hopkins (SimCity Tcl/Tk palette). `documentation/designs/simcity-tool-palette-design.md`
- **p-pyramid-attention** — Attention is an anchored weight mask over a graph;
  cross-exclusion groups act like radio buttons; z-order is short-term memory.
  — Minsky AI Memo 516. `documentation/designs/p-pyramid-attention-overlay.md`

## Method candidates

- **instance-first-play-learn-lift** — Build the working instance before the
  abstraction; lift only what earns its keep. — palmhoo CONSTITUTION Arts. I, VIII.
- **point-dont-copy** — One canonical home; everywhere else points and annotates;
  copying paragraphs breaks edit rights and rots coherence. — palmhoo CONSTITUTION Arts. II-III.
- **declare-constraints-sync** — Declare relationships as constraints and let the
  system keep them true (KR, OpenLaszlo, Svelte runes). — Brad Myers; Hopkins.
  wwsff `characters/don-hopkins/garnet-to-svelte-constraint-ui-lineage.md`
- **coherence-as-journalism** — Every summary declares sources and a verify date;
  staleness is a queue; conflicts are first-class bugs. — palmhoo CONSTITUTION Art. IX, coherence.yml
- **proposals-before-facts** — In shared consequential state, major actions are
  visible proposals on the map before they become facts; loggable, replayable.
  — Hopkins (SimCityNet). wwsff `palmhoo/.../collaborative-microworld-lineage.md`
- **implication-over-simulation** — Offload detail to the player's imagination;
  don't code what implication supplies. — Wright (overlaps simulator-effect; may merge)
- **tools-first-content-second** — Build creation tools before content pipelines.
  — Miyamoto. `designing-inward-miyamoto-principles.md` §9
