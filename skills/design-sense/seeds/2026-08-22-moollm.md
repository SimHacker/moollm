## Lens candidates

- **semantic-mipmap** — Publish every artifact at multiple resolutions (glance →
  interface → protocol → deep why); never load a finer level until the coarser one
  earned it. Operational cousin of stage-magic. — `designs/GLOSSARY.md`, `designs/MOOPMAP.md`
- **comments-as-data** — Comments carry intent machines can't encode in fields;
  design so humans, LLMs, and programs all keep the comment channel. — `skills/yaml-jazz/`
- **directories-as-advertisements** — A listing is a capability index: scanning the
  container answers "what can I do here?" without opening every child. — yaml-jazz, advertisement
- **advertisement-economy** — Intelligence lives in the environment: objects broadcast
  scored offers, agents pick by needs; expansion becomes drop-in objects, not central
  switch statements. — Will Wright / The Sims; `skills/advertisement/`
- **simulator-effect** — Implication beats full simulation; sparse cues, the user's
  imagination is free compute. — Will Wright; `skills/simulator-effect/`
- **gutter-closure** — The punch lands in the gap: what you omit, the reader builds
  better; design the white space, not only the panels. — Scott McCloud; `designs/GLOSSARY.md`
- **robust-first** — Survive > heal > function > optimize; a crashed system is
  infinitely wrong. — Dave Ackley; `skills/robust-first/`
- **postel** — Accept messy input, emit clean output, ask when stakes are high.
  — Jon Postel; `skills/postel/`
- **three-axis-accessibility** — Lasting representations balance human readability,
  LLM sniffability, machine parseability; prefer forms that score on all three.
  — `kernel/constitution-core.md` §3
- **k-line-activation** — A name is a stored attention mask; prefer activation by
  name over pasting the essay. — Minsky; `skills/k-lines/`
- **level-band** — When restoring prior understanding, attach the middle of the
  pyramid: too low imposes stale detail, too high assumes solved. — Minsky 1979; `designs/P-PYRAMID.md`
- **lean-into-latent** — If the pointee is in training, point — the name is the
  activation; spell novel knowledge once, findably. — `skills/no-ai-humansplaining/`
- **sniff-depths** — Structure artifacts so readers sniff glance/structure/full
  without opening everything; depth is a first-class legibility property. — `skills/sniffable-python/`
- **procedural-rhetoric** — Rules are arguments: what you measure, reward, make easy
  or impossible is an ideological claim; design it on purpose or it designs itself.
  — Ian Bogost; `skills/procedural-rhetoric/`

## Method candidates

- **play-learn-lift** — Jazz first, then standards: explore low-stakes → notice
  patterns → formalize; specs-first ships untested abstractions. — `skills/play-learn-lift/`
- **lift-gate** — LIFT is earned: dogfood the concrete instance until it surprises
  you, then abstract. — same
- **worse-is-better** — Simplicity, timing, community beat technical elegance;
  can you remove more? — Richard Gabriel; `skills/format-design/`
- **sister-script** — Put the API at the top so structure is the documentation.
  — Don Hopkins; `skills/sister-script/`
- **sip-before-gulp** — Metadata and sidecars first; open the full body only when
  the sip fails. — `skills/summarize/`
- **melt-then-ladle** — Brew one monolith until ideas cohere, then split into topical
  docs and playbooks. Distinct from accretion: synthesis then shard. — `skills/cauldron/`
- **scry** — Mechanical tools are sensors, not judges: tool reports → LLM interprets
  → iterate. — `skills/cauldron/protocols/SCRY.yml`
- **orthogonal-mixins** — Keep type, rules, presentation, metadata on separate axes;
  compose instances as tiny deltas. — `designs/GAME-PIECES.md`
- **sharp-substrate** — Keep a maximally general sharp mechanism at the bottom;
  everyday work goes through a disciplined protocol on top; don't ban the substrate.
  — Owen Densmore / NeWS; COM; `designs/DIRECTORY-AS-IUNKNOWN.md`
- **query-by-presence** — Discover capabilities by asking "is this interface here?"
  not by hard-wiring a class tree. — `designs/DIRECTORY-AS-IUNKNOWN.md`
- **everything-is-concrete** — Clone a working prototype and override deltas;
  networks of delegation beat taxonomic trees. — Ungar & Smith; `skills/prototype/`
- **latent-space-inheritance** — Parent lists mix filesystem paths and named concepts
  the model already knows; the training set is a prototype store, reify only what
  must be pinned. — `designs/object-system/LATENT-SPACE-INHERITANCE.md`

## Master candidates

- **marvin-minsky** — memory as named reactivation of partial mental states:
  K-lines, P-pyramids, level-bands, cross-exclusion.
- **ian-bogost** — systems as persuasive procedures; critique and author the
  argument encoded in rules.
- **seymour-papert** — learning as building inspectable microworlds; debug is learning.
- **dave-ackley** — survivability above correctness; living computation under failure.
- **richard-gabriel** — ship the "worse" system that wins on simplicity and uptake.
