# Instance First

**Class:** method · **Attribution:** Oliver Steele (*Classes and Prototypes*, 2004); palmhoo CONSTITUTION Arts. I, VIII

> **It's easier to generalize from two examples than from one.**

Implement for one real instance; generalize to a class only when a second case
appears. Build the working instance before the abstraction — prototype cloning,
not class-first taxonomy. Specs-first inverts the order and ships untested
abstractions.
