# Tools First, Content Second

**Class:** method · **Attribution:** Shigeru Miyamoto (GDC 1999); independently Bill Budge, Will Wright

> **Build the making-tools first; the content gets cheap, consistent, and tunable.**

Miyamoto's production order: before making the game, make the tools that make
the game — then content creation is fast, uniform, and adjustable late.
Mario's movement was tuned as a toy in an empty room until it was fun with
nothing to do; only then did levels exist to spend that fun in. The method's
three dividends:

- **Cheapness** — content authored through a tool costs a fraction of content
  authored by hand, and the hundredth level is cheaper than the tenth.
- **Consistency** — the tool enforces the grammar; every level speaks the same
  physics ([one-page-designs](one-page-designs.md) enforced by software).
- **Late tunability** — when the feel changes, regenerate; hand-built content
  fossilizes decisions the tool would keep liquid
  ([tuned-emergence](tuned-emergence.md) needs this liquidity).

The radical extension is handing the tools to the players: Budge shipped the
construction set *as* the game; Wright's hobby model made player content the
content ([player-as-storyteller](player-as-storyteller.md)). The tool you build
for yourself is the possibility space you later sell.
