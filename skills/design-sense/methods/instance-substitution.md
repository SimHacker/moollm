# Instance Substitution

**Class:** method · **Attribution:** Oliver Steele (LZX / OpenLaszlo)

> **Instance and class should be syntactically parallel.**

An instance and its class definition should read the same, so one can replace the
other without changing semantics — an LZX tag *is* a class. When promotion from
instance to class is a rename rather than a rewrite, instance-first costs nothing.
