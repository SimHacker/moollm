# Reverse Diagrams

**Class:** method · **Attribution:** Chaim Gingold (*Building SimCity*, MIT Press 2024)

> **Diagram the shipped system until the black box opens.**

Reverse-engineer an existing system into dense, beautiful explanatory diagrams —
not the design docs it started from, but the truth of what shipped. Gingold's
SimCity reverse diagrams map the actual simulation (RCI, traffic, power, the
cellular automata) at a level of care usually reserved for architecture that
hasn't been built yet. The method honors a working system as a text worth close
reading, and produces the missing manual its own creators never wrote.

The forward path: with Chaim's explicit permission, Micropolis is bringing the
static diagrams to life as interactive first-class cards — reverse diagrams
becoming [explorable explanations](explorable-explanations.md), wired to a live
simulator.
