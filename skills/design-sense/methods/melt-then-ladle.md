# Melt, Then Ladle

**Class:** method · **Attribution:** moollm cauldron skill
**Dispatch:** whole skill at moollm `skills/cauldron/` — load it; this entry is the design-sense pointer.

> **One pot until it coheres; then serve bowls.**

For cross-cutting work: brew one monolith until the ideas cohere, then split into
topical docs and executable playbooks so cheap executors can run in parallel.
Distinct from accretion — synthesis phase then shard, not growth then tune. Includes
SCRY: mechanical tools are sensors, not judges; tool reports → interpretation → iterate.
