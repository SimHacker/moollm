# Stomach — pocket universe

Two-Toll's gut is a directory. Everything he eats goes under `contents/`:
adventurers, treasures, axes, and — when `location` is set to himself —
himself.

This is a single pocket universe (Donnie Darko recursive): eating himself
does not spawn a second stomach folder; it relocates him into this one.
He can still front a mind from inside. The axe can be fought with, thrown,
caught, eaten (lands here), recovered, and eaten again.

See `STOMACH.yml` for the protocol. Carried gear lives in `../inventory/`.
