# Adventurers (digested)

Getting eaten is a move, not a copy: set the character's `location`
to this directory's path and they are in the stomach. Their canonical
character file stays wherever it lives; only the pointer moves.

Want local state? Drop a stub `.yml` here that **inherits from the
character** and specializes them in the context of this room —
spattered in troll digestive juices, down one boot, noting which
mind collected them and whether they paid first.

Customs note: prototype pockets stay empty at borders; this subdir
is instance-local hoard, not luggage.
